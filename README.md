# Ukrainian Cases: Practice

Free, interactive practice pages for English-speaking learners of Ukrainian, working through the grammatical
case system one case at a time. Built with input from a native-speaker Ukrainian tutor.

No sign-up, no tracking, no backend; everything runs in your browser and your progress is saved locally on
your own device.

**Start here: [hazymat.github.io/ukrainian-cases](https://hazymat.github.io/ukrainian-cases/)**

## Pages

- [Genitive case](https://hazymat.github.io/ukrainian-cases/genitive_case.html): Родовий відмінок
- [Accusative case](https://hazymat.github.io/ukrainian-cases/accusative_case.html): Знахідний відмінок
- [Genitive vs Accusative](https://hazymat.github.io/ukrainian-cases/genitive_vs_accusative.html): contrastive practice

More cases are being added over time.

## About this project

Each page assumes only the Nominative case as prior knowledge, so they can be worked through in any order,
though Genitive and Accusative are traditionally taught first. See [CONVENTIONS.md](CONVENTIONS.md) for the
house style and content conventions used throughout.

Corrections and suggestions welcome via [GitHub Issues](https://github.com/hazymat/ukrainian-cases/issues).
