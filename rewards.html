Roasts / Rewards Library

Internal reference, not for learners. This is a tone guide, not a content list to browse for fun. It documents the voice the completion celebration is meant to speak in: affectionate, mildly cheeky commentary built around Ukrainian food and cultural symbols, there to keep the practice sessions light without ever tipping into unkind. It's not linked from anywhere on the site. Below a strong score the register is playful ribbing, family-friendly, never mean-spirited; from a strong score up it turns warm and genuinely proud. Use this page to calibrate any new line against that established register rather than inventing tone from scratch. It loads shared/rewards-data.js directly, the same file shared/app.js uses, so this list is always exactly what's live: edit a line in that one file and both update.

Picked per exercise via a site-wide shuffle bag: each tier's pool is dealt out in shuffled order and only reshuffles once every line has been seen. Whichever line gets drawn sticks for that exercise across reloads, until it's reset. Every tier except 10/10 gets a dynamic N/total. Lead-in! prefix added in code (see TIER_LEADS in shared/app.js) ahead of the line shown below; the 10/10 pool already opens each line with its own score/exclamation.
